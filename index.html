EPG Visualiser

SOFTWARE
Build any DNA profile — single-source, mixture, degraded, with stutter or other artefacts — and see it rendered as an electropherogram-style trace. Add a locus, assign it a dye channel, then list its alleles with a size (bp), a peak height (RFU), and a type. The preview below updates live. When you're happy with it, download it as a PNG to drop into slides, worksheets, or Kahoot/Mentimeter question images.

This is an illustrative rendering tool, not real instrument software — peaks are drawn as smooth Gaussian curves from the numbers you enter, not derived from real fragment data.
